# Front Matter

This file holds the project report's front matter in markdown form. At pandoc conversion time, the file is merged ahead of the chapter files and rendered against a `reference.docx` that supplies the Scaler-prescribed styles (Times New Roman 14pt headings / 12pt body, 1.5 line spacing, 1.25" left/right margins, 1" top/bottom margins).

The seven front-matter components the Scaler template prescribes, in order:

1. Title page
2. Certification
3. Declaration
4. Acknowledgment
5. Table of Contents
6. List of Tables
7. List of Figures

Items 5, 6, and 7 are generated by Word (or by pandoc at build time with the `--toc`, `--lof`, and `--lot` flags) from the styled headings, figure captions, and table captions that the chapters already carry. The three items below are placeholder markers that pandoc replaces with the generated content. No manual drafting is required for them.

Items 1 through 4 are drafted below. Placeholders marked `<FILL IN ...>` are the fields the candidate must personalise before the final submission; every other line of prose is final.
