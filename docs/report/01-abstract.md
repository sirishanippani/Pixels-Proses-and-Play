# 1. Abstract

Pixels, Proses & Play is a server-side-rendered blogging platform built in Java and Spring Boot and submitted as the capstone for the Scaler Neovarsity Backend Specialization. The project began as an early-stage learning build and was reshaped through a seven-phase refactor pipeline into a form intended to hold up under the scrutiny expected of a production application. The work used strangler-fig refactoring behind a stable public interface, with a safety-net test suite written before structural change and extended at each phase. The refactored codebase introduced a service seam that accepts primitives to structurally close mass assignment, form data transfer objects with declarative Jakarta Bean Validation constraints, OWASP-allowlisted HTML stored at the persistence layer, versioned Flyway schema migrations held in three parallel per-vendor directories, Open Session In View disabled in favour of explicit `@EntityGraph` fetch plans at each repository call site, a token-based CSS design system supporting light and dark themes from one source, and internationalisation-ready flash messaging routed through Spring's `MessageSource`. The platform is packaged as a multi-stage container image and deployed to a free-tier platform-as-a-service combination (Render for the web runtime and Neon for managed PostgreSQL) at `https://pixels-proses-and-play.onrender.com`, with external liveness probing through UptimeRobot. Measured results on the home-page feed show the query count falling from twenty-one to one per request after the fetch-plan rework, with the median handler time falling from thirty-eight milliseconds to six and variance across requests collapsing by a comparable factor. The techniques demonstrated in the project transfer directly to backend web applications in enterprise Java, to REST and GraphQL backends behind a separate front-end, and to the broader class of financial-services and e-commerce platforms that share the Spring Boot plus PostgreSQL plus Flyway baseline stack.
